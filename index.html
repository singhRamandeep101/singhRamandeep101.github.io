AI-Enhanced Domestic Helper Hiring App SEP 2024 – JUN 2025
Final Year Project, HKMU · Project Lead & Full-Stack Developer · 4-person team

A full-stack Android platform streamlining domestic helper hiring in Hong Kong. I led the team from design to demo — owning the architecture, the ML matching engine, and the multilingual stack.

  • Hybrid rule-based + scikit-learn engine (via Chaquopy) parses PDF CVs with pdfplumber and ranks candidate–employer matches automatically
  • Real-time chat translated across English, Cantonese, Filipino and Indonesian via MyMemory API
  • Firebase Auth, Realtime Database and Cloud Messaging for chat, booking and notifications
  • Jitsi Meet integration for in-app video interviews — no external app needed
  • Role-based admin panel with advanced search and filtering
  • Delivered a 35% efficiency gain over traditional manual hiring workflows

SmartWallet HK 2026 · PERSONAL PROJECT
Flutter · Offline-First · Bilingual EN / 繁體中文 · CI-Tested

An offline-first personal finance tracker built for Hong Kong — HKD budgets, recurring transactions and spending insights. Built solo in Flutter as a second mobile stack: tested, CI-checked and documented.

  • Riverpod state management with a Drift (SQLite) database — amounts stored as integer cents to avoid floating-point money errors
  • Spending-insights screen with donut and trend charts drawn from scratch with CustomPainter — no chart library
  • Recurring weekly/monthly transactions materialised on launch, with capped catch-up and bank-style month-end clamping
  • Monthly category budgets with overspend warnings, plus CSV export of the full ledger
  • Unit-tested money, CSV and date logic — GitHub Actions CI runs analyze + tests on every push
