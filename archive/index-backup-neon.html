001 · Final Year Project · HKMU 2024–2025
AI-Enhanced Domestic Helper Hiring App
Full-Stack Android · ML Matching · Firebase · Multilingual

A production-grade Android platform streamlining domestic helper hiring in Hong Kong. I led a 4-person team from design to deployment — building an ML-powered CV matching engine, multilingual real-time chat, and integrated video interviewing.

  • Hybrid rule-based + scikit-learn ML engine parses PDF CVs and matches candidates to employers automatically
  • Real-time translation across English, Cantonese, Filipino, and Indonesian via MyMemory API
  • Firebase realtime chat, booking management, and push notifications
  • Jitsi Meet integration for in-app video interviews — no external app needed
  • Role-based admin panel with advanced search and filtering for user management
  • Delivered 35% efficiency gain over traditional manual hiring workflows
